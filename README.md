# ❤️ Heart Disease Prediction using Machine Learning

## Project Overview
This project aims to **predict the likelihood of heart disease** based on health data, leveraging the power of machine learning algorithms. It provides healthcare professionals with an **early diagnostic tool** for heart disease, helping improve early detection and treatment. The model considers various health metrics, such as age, cholesterol levels, blood pressure, smoking, and more.

## 🔧 Technologies Used
- **🖥️ Language:** Python
- **📚 Libraries:**
  - `scikit-learn` (Machine Learning)
  - `pandas` (Data Manipulation)
  - `numpy` (Numerical Operations)
  - `matplotlib` & `seaborn` (Data Visualization)
- **💡 Modeling Algorithms:**
  - Logistic Regression
  - Decision Tree
  - Random Forest
  - K-Nearest Neighbors (KNN)
  - Support Vector Machine (SVM)

## 📊 Dataset
- **📍 Source:** [Kaggle Cardiovascular Disease Dataset](https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset/data)
- **🩺 Features include:**  
  - Age, gender, cholesterol levels, blood pressure (ap_hi, ap_lo), smoking, alcohol consumption, physical activity, and more.
  - The dataset serves as a foundation for training machine learning models to predict heart disease risk.

## 🏆 Results
The project evaluates multiple machine learning models, including **Random Forest** and **SVM**. The **Random Forest** algorithm demonstrated the highest accuracy in predicting heart disease. It provides a reliable solution for early diagnosis. The model's performance was evaluated using accuracy, precision, recall, and F1-Score.
