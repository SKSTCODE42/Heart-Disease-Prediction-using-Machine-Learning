Heart Disease Prediction using Machine Learning

## Project Overview
This project aims to develop a machine learning model that predicts the likelihood of heart disease based on health data. The goal is to assist healthcare professionals in diagnosing heart disease early.

## Technologies Used
- **Language:** Python
- **Libraries:** `scikit-learn`, `pandas`, `numpy`, `matplotlib`, `seaborn`
- **Modeling Algorithms:** Logistic Regression, Decision Tree, Random Forest, KNN, SVM

## Dataset
- **Source:** [UCI Heart Disease Dataset](https://archive.ics.uci.edu/ml/datasets/Heart+Disease)
- Contains medical data for heart disease prediction (age, cholesterol levels, blood pressure, etc.)

## Project Structure
```

Heart-Disease-Prediction-using-Machine-Learning/
├── data/                 # Dataset files
├── notebooks/            # Jupyter notebooks for exploration and modeling
├── models/               # Saved trained models
├── visuals/              # Plots and charts
├── main.py               # Main script to run the prediction model
├── requirements.txt      # List of dependencies
└── README.md             # Project documentation

```

## How to Run
1. Clone the repository
2. Install dependencies:
```

pip install -r requirements.txt

```
3. Run `main.py` or use the Jupyter notebooks for further exploration.

## Results
The project evaluates different models, and the Random Forest and SVM algorithms show the best results in terms of prediction accuracy.
