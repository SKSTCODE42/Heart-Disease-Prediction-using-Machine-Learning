# ❤️ Heart Disease Prediction using Machine Learning

## Project Overview
This project aims to **predict the likelihood of heart disease** based on health data, leveraging the power of machine learning algorithms. It assists healthcare professionals by offering an **early diagnostic tool** for heart disease, thereby improving early detection and treatment. The model takes into account several health metrics such as age, cholesterol levels, blood pressure, and more.

## 🔧 Technologies Used
- **🖥️ Language:** Python
- **📚 Libraries:**
  - `scikit-learn` (Machine Learning)
  - `pandas` (Data Manipulation)
  - `numpy` (Numerical Operations)
  - `matplotlib` & `seaborn` (Data Visualization)
- **💡 Modeling Algorithms:**
  - Logistic Regression
  - Decision Tree
  - Random Forest
  - K-Nearest Neighbors (KNN)
  - Support Vector Machine (SVM)

## 📊 Dataset
- **📍 Source:** [UCI Heart Disease Dataset](https://archive.ics.uci.edu/ml/datasets/Heart+Disease)
- **🩺 Features include:**  
  - Age, sex, chest pain type, cholesterol levels, blood pressure, and more.
  - The dataset serves as a foundation for training machine learning models to predict heart disease risk.

## 🏆 Results
The project evaluates multiple machine learning models, including **Random Forest** and **SVM**. The **Random Forest** algorithm demonstrated the highest accuracy in predicting heart disease, providing a reliable solution for real-time medical applications. The performance of each model was assessed using key metrics such as accuracy, precision, recall, and F1-Score.
